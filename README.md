# Calculadora web

Esta versión se visualiza desde navegador.

## Ejecutar localmente

```bash
python3 -m http.server 8000
```

Luego abre en tu navegador:

- `http://localhost:8000/web/`

## Operaciones soportadas

- Suma (`+`)
- Resta (`-`)
- Multiplicación (`*`)
- División (`/`) con validación de división por cero.
